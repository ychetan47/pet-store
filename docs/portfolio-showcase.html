Core Business & Technical Highlights

📦 Dual Portals (Customer & Admin)

Independent, decoupled React 19 SPAs: a high-conversion storefront with product filtering, dynamic cart, and checkout, paired with a real-time admin management portal.

⚡ Transactional Outbox Pattern

Eliminates dual-write bugs during order placement. Database updates and outbound Kafka events are committed atomically, guaranteeing at-least-once event delivery.

🔄 Asynchronous Event Sourcing

Order events trigger non-blocking stock reservations in Inventory Service and real-time email/push dispatches in Notification Service via Apache Kafka KRaft cluster.

🔒 Defense-In-Depth Security

Stateless JWT authentication, BCrypt password hashing, Spring Cloud Gateway centralized authorization, and zero trust internal Kubernetes network policies.

Production Kubernetes Manifest Architecture

☸️ StatefulSets with Dynamic Storage

PostgreSQL 16 and Kafka 3.7 are deployed as Kubernetes StatefulSets with dedicated volumeClaimTemplates requesting standard-rwo persistent disks, ensuring data survivability across pod restarts or node rescheduling.

🌐 GKE Health Checks & BackendConfig

Spring Boot Actuator health endpoints (/actuator/health) are integrated with Google Cloud Load Balancer via custom BackendConfig CRDs, ensuring zero downtime rolling updates and proactive traffic redirection.

🔒 Secret & Config Decoupling

All sensitive credentials (database passwords, JWT secret keys) are managed through Kubernetes Secrets and injected into container environments via secretKeyRef, preventing secrets leakage into source control.

🚀 Automated One-Click Deployment

Includes deploy-all.sh that orchestrates the rollout sequence: Namespace ➔ Secrets ➔ ConfigMaps ➔ StatefulSets (Storage & Message Broker) ➔ Microservices ➔ Gateways & Ingress.

Clean Repository Structure & Git Branching Strategy
🌿
Professional Git Flow Architecture: The codebase maintains a clean, production-ready branching model where main represents stable releases, develop aggregates sprint deliverables, and localized features branch into feature/*. All deployment manifests are centralized in deploy/k8s/ and deploy/cloud-run/ without altering microservice business code.

🛠️ Local Hybrid Developer Velocity

Developers run backing infrastructure (postgres, kafka) via Docker Compose while running their microservice or React frontend directly on their workstation for instant Vite HMR and sub-second Java code debugging.

📦 Multi-Architecture Container Builds

Docker container images are built specifically with --platform linux/amd64 multi-stage pipelines to ensure seamless binary execution between developer Apple Silicon (ARM64) Macs and Google Cloud x86_64 nodes.
